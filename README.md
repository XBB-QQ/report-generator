# report-generator

智能护理表单模板生成器，当前版本 **v8.12**。

## 必读注意事项

> <span style="color:red">**1. 模板生成及后续修改必须保持在同一个会话中。** 不要在生成后另开会话继续修改，避免上下文丢失导致重复解析、控件配置不一致或误改其他区域。</span>
>
> <span style="color:red">**2. 为模板制作固定一个统一的工作目录。** 所有模板的源文件、生成脚本、生成的 ZIP、手动修复后导出的模板都集中保存在同一个目录空间中，便于 AI 持续查找、修改和核对，不要分散到多个目录。</span>
>
> <span style="color:red">**3. 首次生成效果不佳时，可手动修复后回喂 AI。** 可先在系统中手动修复并导出模板，再将导出的模板提供给 AI，用于分析差异、补齐不足并改进后续生成结果。</span>
>
> <span style="color:red">**4. AI 生成的模板报错时，提供 Console 报错截图。** 可按 `F12` 打开浏览器开发者工具，将 Console 中的报错内容截图提供给 AI；AI 会据此分析并修复问题。</span>

## 学习与使用说明

- 学习模板制作视频：[点击查看](https://bsoft.yunxuetang.cn/kng/#/video/preview/detail?kngId=51ef4280-d52c-48fd-bbbb-d9f88f0ad57b&previewType=2&status=4)
- 本 Skill 仅用于提升制作效率，生成结果不代表可直接投入正式环境；正式使用前必须经过人工审核。
- 手动制作模板仍是实施人员必须掌握的基本技能，AI 不能替代对模板规范的理解与判断，建议先学会手工制作再借助本 Skill 提效。
